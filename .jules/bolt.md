## 2026-07-21 - Verify Sandbox Environment State Across Sessions
**Learning:** The sandbox environment might be reset between different user interaction sessions or tasks, meaning files may not reflect previous session memories. Assuming a file is already optimized based on historical memory can lead to missing opportunities or incorrect assumptions.
**Action:** Always inspect the actual codebase files as the initial source of truth at the start of a task, rather than solely relying on historical memories of completed optimizations.
